# SCR-01 URL登録画面

作成日: 2026-10-29
ステータス: レビュー待ち
対応要件: FR-01, FR-02, FR-03
使用API: [API-01](../api/API-01_create-short-url.md)

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| パス | `/` |
| コンポーネント | `features/short-urls/RegisterPage.tsx` |
| 目的 | 元のURLを入力して短いURLを発行し、コピーする |

## 2. レイアウト

```
┌──────────────────────────────────────────────┐
│ URL Shortener        [登録]  [一覧]           │  ← 共通ヘッダー（Layout）
├──────────────────────────────────────────────┤
│ URLを短縮する                                 │
│ 元のURL                                       │
│ [https://...                          ] [短縮]│
│ ※エラーメッセージ（エラー時のみ）              │
│                                              │
│ ┌ 発行結果（成功時のみ）──────────────────┐   │
│ │ http://localhost:8000/aB3xK9q  [コピー] │   │
│ │ 元のURL: https://example.com/...        │   │
│ └─────────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

## 3. 項目定義

| No | 項目 | 種類 | 内容 |
| --- | --- | --- | --- |
| 1 | 元のURL | 入力（`type="url"`、`required`、`maxLength=2048`） | ラベル「元のURL」と関連付ける |
| 2 | 短縮 | ボタン（submit） | 送信中は無効化し、表示を「短縮中…」にする |
| 3 | エラーメッセージ | テキスト（`role="alert"`） | 422は `errors.original_url[0]`、429・その他は 4章のメッセージ |
| 4 | 短いURL | リンク（新しいタブで開く、`rel="noopener noreferrer"`） | APIの `short_url` |
| 5 | コピー | ボタン | `navigator.clipboard.writeText` で短いURLをコピー。成功時に2秒間「コピーしました」と表示 |
| 6 | 元のURL（結果） | テキスト | APIの `original_url` |

## 4. 動作

| 契機 | 動作 |
| --- | --- |
| 短縮ボタン押下 | ブラウザ標準の入力チェック後、API-01を呼び出す |
| API成功（201） | 発行結果を表示し、入力欄を空にする。一覧のキャッシュを無効化する（TanStack Query） |
| API失敗（422） | 入力欄の下にAPIのエラーメッセージを表示する。入力値は保持する |
| API失敗（429） | 「リクエストが多すぎます。時間をおいて再度お試しください。」 |
| API失敗（その他・通信エラー） | 「エラーが発生しました。時間をおいて再度お試しください。」 |
| 再送信 | 前回のエラー・結果を消してから送信する |
| コピー失敗 | 「コピーできませんでした」と表示する |

- 入力チェックの正はサーバー側とする（ブラウザの `type="url"` は `javascript:` を通すため、スキーム制限はAPIで行う）
