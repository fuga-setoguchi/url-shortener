# SCR-02 URL一覧画面

作成日: 2026-10-29
ステータス: 確定（2026-10-30）
対応要件: FR-07, FR-08
使用API: [API-02](../api/API-02_list-short-urls.md)

## 1. 概要

| 項目 | 内容 |
| --- | --- |
| パス | `/urls?page={n}` |
| コンポーネント | `features/short-urls/UrlListPage.tsx` |
| 目的 | 登録済みURLとクリック数を確認する |

## 2. レイアウト

```
┌──────────────────────────────────────────────────────────────┐
│ URL Shortener        [登録]  [一覧]                           │
├──────────────────────────────────────────────────────────────┤
│ 登録済みURL一覧（全45件）                                      │
│ ┌──────────────┬────────────────────┬────────┬────────────┐  │
│ │ 短いURL       │ 元のURL             │ クリック数│ 作成日時     │  │
│ ├──────────────┼────────────────────┼────────┼────────────┤  │
│ │ .../aB3xK9q  │ https://example... │     12 │ 2026/10/29 16:30 │
│ └──────────────┴────────────────────┴────────┴────────────┘  │
│                  [前へ]  1 / 3  [次へ]                         │
└──────────────────────────────────────────────────────────────┘
```

## 3. 項目定義

| No | 項目 | 内容 |
| --- | --- | --- |
| 1 | 件数 | `meta.total` |
| 2 | 短いURL | `short_url` をリンク表示（新しいタブ、`rel="noopener noreferrer"`） |
| 3 | 元のURL | `original_url`。リンクにせずテキストで表示する（6.2の多層防御）。長い場合は省略表示（CSSの `text-overflow: ellipsis`）し、`title` 属性で全文を確認できる |
| 4 | クリック数 | `clicks_count`（右寄せ） |
| 5 | 作成日時 | `created_at` をローカル時刻の `YYYY/MM/DD HH:mm` で表示 |
| 6 | 前へ / 次へ | ボタン。先頭・最終ページではそれぞれ無効化する |
| 7 | ページ表示 | `{meta.current_page} / {meta.last_page}` |

## 4. 動作

| 状態・契機 | 表示・動作 |
| --- | --- |
| 初期表示 | URLクエリ `page`（無い・1以上の整数でないなら1）でAPI-02を呼び出す |
| 読み込み中 | 「読み込み中…」 |
| 0件 | 「まだURLが登録されていません」と、登録画面へのリンク |
| 取得失敗 | 「一覧を取得できませんでした」と「再試行」ボタン（`refetch`） |
| 前へ / 次へ押下 | URLクエリ `page` を更新し、該当ページを取得する（ブラウザの戻る・進むに対応） |

- ページ番号をURLクエリに持たせる理由：再読み込みやURL共有で同じページを表示できるようにするため
