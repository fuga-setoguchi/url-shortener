# API-03 リダイレクト

作成日: 2026-10-29
ステータス: 確定（2026-10-30）
対応要件: FR-04, FR-05, FR-06, NFR-02

## 1. 概要

短いURLへのアクセスを元のURLへ転送し、クリック記録ジョブをキューに投入する。

| 項目 | 内容 |
| --- | --- |
| メソッド | GET |
| パス | /{code} |
| パス制約 | `code` は `[A-Za-z0-9]{7}` |
| 認証 | なし |
| ミドルウェア | なし（セッション・Cookieを使わない） |
| 処理クラス | RedirectController → RecordClick（ジョブ） |

## 2. 処理

1. `code` が制約に合わない場合はルートに一致せず404
2. `ShortUrl::where('code', $code)->firstOrFail()` で検索する（大小文字を区別。未登録なら404）
3. `RecordClick::dispatch($shortUrl->id, now())` でクリック記録ジョブを投入する
4. `302 Found`、`Location: {original_url}` を返す

キューワーカー（queue サービス）が RecordClick を処理し、clicks に1行挿入する。

| ジョブ設定 | 値 | 理由 |
| --- | --- | --- |
| 再試行回数（`$tries`） | 3 | DBの一時的な失敗に備える |
| 失敗時 | failed_jobs に記録 | 原因調査と `queue:retry` での再実行を可能にする |

## 3. レスポンス

| ステータス | 条件 | 内容 |
| --- | --- | --- |
| 302 | コードが存在する | `Location` ヘッダーに元のURL |
| 404 | コードが未登録・形式不正 | Laravel標準の404ページ |

## 4. 補足

- 301ではなく302を使う理由：301はブラウザにキャッシュされ、2回目以降のアクセスがサーバーに届かずクリックを記録できないため
- クリック記録を非同期にする理由：転送の応答をDB書き込みの完了まで待たせないため
- `clicked_at` はジョブ処理時刻ではなくアクセス時刻を渡す（キューの遅延によって時刻がずれないため）
- ボットやプリフェッチによるアクセスもクリックとして数える（MVPでは区別しない）
