# 要件定義書

作成日: 2026-10-29
ステータス: レビュー待ち
参照: [プロジェクト計画書](00_project-plan.md)

## 1. 目的

長いURLを短いURLに変換し、短いURLへのアクセスを元のURLへ転送するWebサービスを提供する。MVPはURL登録・リダイレクト・一覧表示の3機能とする。

## 2. 利用者と前提

- 利用者はローカル環境で動かす開発者・閲覧者1名を想定する（ログインなし）
- 一覧はローカル環境の全件を対象とする
- 本番公開はしない

## 3. 用語

| 用語 | 意味 |
| --- | --- |
| 元のURL（original_url） | 利用者が登録する転送先のURL |
| 短縮コード（code） | 短縮URLを識別する英数字7文字の文字列 |
| 短いURL（short_url） | `{短縮URLのベースURL}/{code}` 形式のURL |
| クリック | 短いURLへのアクセスにより転送が成功した1回 |

## 4. 機能要件

| ID | 機能 | 要件 | 対応設計 |
| --- | --- | --- | --- |
| FR-01 | URL登録 | 元のURLを受け取り、一意な短縮コードを発行して保存し、短いURLを返す | API-01 / SCR-01 |
| FR-02 | URL登録の入力検証 | 不正なURLは登録せず、理由を画面に表示する（検証規則は 6章） | API-01 / SCR-01 |
| FR-03 | コピー | 発行された短いURLをワンクリックでクリップボードへコピーできる | SCR-01 |
| FR-04 | リダイレクト | 短いURLへのアクセスで元のURLへ302で転送する | API-03 |
| FR-05 | クリック記録 | 転送成功時にクリック日時を記録する。記録は非同期で行う | API-03 |
| FR-06 | 存在しないコード | 未登録・形式不正のコードには404を返す | API-03 |
| FR-07 | 一覧表示 | 登録済みURLを作成日時の新しい順に、元のURL・短いURL・クリック数・作成日時とともに表示する | API-02 / SCR-02 |
| FR-08 | ページング | 一覧は1ページ20件で表示し、前後のページへ移動できる | API-02 / SCR-02 |

## 5. 非機能要件

| ID | 区分 | 要件 |
| --- | --- | --- |
| NFR-01 | 環境 | `docker compose up` だけでDB・バックエンド・キューワーカー・フロントエンドが起動する |
| NFR-02 | 性能 | リダイレクトはクリック記録の完了を待たずに応答する |
| NFR-03 | セキュリティ | http・https以外のスキーム（`javascript:` など）を登録させない |
| NFR-04 | セキュリティ | 短縮コードは推測されにくいランダム文字列とする（連番を使わない） |
| NFR-05 | セキュリティ | URL登録APIにレート制限（1分あたり60回/IP）を設ける |
| NFR-06 | 型安全 | PHPは `declare(strict_types=1)` と型宣言、Larastan最大レベル。TSは `strict: true`、APIの型はOpenAPIから生成する |
| NFR-07 | 品質 | 静的解析・整形チェック・自動テストをGitHub Actionsで実行し、すべて通過したものだけをマージする |
| NFR-08 | 時刻 | DBにはUTCで保存し、APIはISO 8601（タイムゾーン付き）で返し、画面は利用者のローカル時刻で表示する |

## 6. 設計論点の決定

計画書 6章の論点を以下のとおり確定する。

| 論点 | 決定 | 理由 |
| --- | --- | --- |
| 短縮コードの生成方式 | 英数字（`[A-Za-z0-9]`）ランダム7文字 | 62^7 ≒ 3.5兆通りあり衝突がほぼ起きず、連番のように推測されない |
| 衝突時の扱い | DBの一意制約違反を検知して再生成（最大3回） | 事前の存在チェックは競合状態を防げないため、一意制約を最終的な保証とする |
| コードの大小文字 | 区別する（DB照合順序を `utf8mb4_bin`） | MySQLの既定照合順序は大小文字を区別せず、`abc` と `ABC` が衝突扱いになるため |
| URLのバリデーション | 必須・文字列・URL形式・スキームはhttp/httpsのみ・最大2048文字 | 危険なスキームを弾き、極端に長い入力を防ぐ。2048文字は主要ブラウザで扱える目安 |
| リダイレクトのステータス | 302 | 301はブラウザにキャッシュされ、2回目以降のクリックを記録できないため |
| クリック記録の方式 | Laravel Queue（databaseドライバ）で非同期 | 転送の応答を遅らせないため。追加ミドルウェア（Redis等）不要で構成が簡素 |
| 存在しないコード | 404 | 誤ったコードを正常と誤認させないため |
| 短縮URLのドメイン | 環境変数 `SHORT_URL_BASE`（既定は `APP_URL` = `http://localhost:8000`） | ローカルではAPIと同じホスト。将来の別ドメイン化に設定だけで対応できる |
| 一覧の件数 | ページング（20件/ページ） | 件数が増えても応答サイズと描画量を一定に保つため |

## 7. 対象外

- 本番デプロイ、独自ドメイン、アクセス元の詳細分析
- 将来拡張（有効期限、カスタムコード、クリック推移グラフ、ログイン）はMVP完成後に検討する
- 登録済みURLの編集・削除
- 同じ元のURLを複数回登録した場合の重複排除（登録ごとに別の短縮コードを発行する）
